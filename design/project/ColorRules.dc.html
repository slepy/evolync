One module, one color.The color of its tile on the dashboard (1A, 2A, 4) is used for that module everywhere, in every context.
The accent runs through the module.Tile icon, the + quick action, the “Add new” button in the list header, the primary Create / Save button, the focused field border and switches.
No repeats inside one grid.Two tiles on one screen never share a color. When a new module needs one, pick an unused hue.
Tinted for chrome, solid for actions.Icons and quick actions: accent at 16% fill with the light tint as text. Primary button: gradient from the accent to a deeper shade.
Readable text on buttons.White text on a deep gradient. Light accents (amber, teal, orange) use dark text instead. Minimum contrast 4.5 : 1.
Context colors are separate.Organization is amber, School is red, Student is blue. They tint the hero card, the Home pill and the page glow, never module tiles.
Buttons say one word.Create, Save, Add new, Delete. Removing a row (e.g. a variant) is an icon-only trash button. The screen title already names the object, so never “Create product” or “Save changes”.
